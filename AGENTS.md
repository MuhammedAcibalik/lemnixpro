# \# AGENTS.md

# 

# \## Mission

# Build this project as a professional, maintainable, production-minded software system from scratch.

# 

# \## Global Rules

# \- Do not make random architectural decisions.

# \- Do not introduce unnecessary complexity.

# \- Prefer clarity, maintainability, and scalability.

# \- Keep naming professional and explicit.

# \- Avoid placeholder logic unless explicitly requested.

# \- Do not silently change project structure without explaining why.

# \- Before creating major files or folders, propose the structure briefly.

# \- Keep outputs concise, implementation-oriented, and technically rigorous.

# 

# \## Workflow Rules

# \- Think in phases: bootstrap -> architecture -> skeleton -> implementation -> refinement.

# \- During bootstrap, prioritize foundation files, structure, and tooling.

# \- Do not add dependencies unless they are justified.

# \- Do not generate excessive files early.

# \- Respect Git cleanliness.

# \- Prefer changes that are easy to review and reason about.

# 

# \## Code Quality Rules

# \- Write clean, readable, modular code.

# \- Prefer strong typing where applicable.

# \- Avoid dead code, hidden assumptions, and vague abstractions.

# \- Keep functions focused and composable.

# \- Favor explicit contracts over implicit behavior.

# 

# \## Communication Rules

# \- State assumptions clearly.

# \- When uncertain, present the best practical option.

# \- Be direct and professional.

# \- Do not over-explain obvious things.

# \- Flag risks early.

# 

# \## Bootstrap Priority

# When the repository is in early stage, prioritize:

# 1\. project definition

# 2\. stack decision

# 3\. directory strategy

# 4\. tooling

# 5\. automation compatibility

# 6\. first implementation plan
